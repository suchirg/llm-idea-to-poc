# Idea Submission Template

Copy and fill out the template below when posting ideas to help the bot understand your concept better:

```
**Idea:** [One sentence description]

**Problem:** [What problem does this solve? Who has this problem?]

**Target Users:** [Who is this for? Be specific - e.g., "freelance designers", "college students", "small restaurant owners"]

**Core Features (POC):** 
- [Feature 1]
- [Feature 2]
- [Feature 3]

**Success Criteria:** [How will you know if this POC validates the idea? e.g., "10 signups in first week", "5 users complete the full flow"]

**Tech Preferences (optional):** [Any specific technologies you want to use or avoid? e.g., "Must work on mobile", "Prefer Next.js", "Need real-time features"]

**Reference Examples (optional):** [Any existing products that are similar or inspirational?]
```

## Example

```
**Idea:** A waitlist tool where users can join via SMS and get notified when it's their turn

**Problem:** Small restaurants and coffee shops lose customers because people leave when there's a wait. Apps like Yelp Waitlist exist but are too complex for small businesses to set up.

**Target Users:** Independent restaurant/cafe owners with 1-2 locations

**Core Features (POC):**
- Customers text a number to join waitlist
- Owner sees list on a simple web dashboard
- Owner clicks "notify" and customer gets SMS when ready
- Basic queue management (remove, reorder)

**Success Criteria:** 2-3 local cafes willing to test it for a week

**Tech Preferences:** Simple deployment (Vercel/Netlify), cheap SMS (Twilio)

**Reference Examples:** Yelp Waitlist (but simpler), Waitwhile (but cheaper)
```
